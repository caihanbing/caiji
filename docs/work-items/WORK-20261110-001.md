## 工作概述

依据用户批准的高保真稿，统一工资与账单首页、汇总、年度报告和明细的相似视觉表现。账单年账单累计卡使用“累计结余”；分类明细补足分类图标并采用一致的图标记录行；报告排行金额使用首页相同字号、颜色和正负符号；工资收入项明细取消月份分组并将日期显示为“6月25日”格式。保留各页面原有业务结构、期间筛选、摘要、账单编辑及工资记录编辑/删除路径。发布版本为 0.5.8 / versionCode 23。

## 范围与验收

### REQ-001 — 报告标签与排行金额语义

- **需求**：年账单累计卡显示“累计结余”；工资年报告收入项金额与工资首页记录金额一致，显示加号、收入绿、16sp 半粗；账单年报告分类金额与账单首页支出一致，显示负号、正文色、16sp 半粗；排行榜金额限宽140dp并在长值下省略，保持名称和金额列不重叠。
- **验收标准**：真实 Compose 仪器测试验证文案、金额符号、字号和金额节点颜色；320dp/1.3倍字级下长分类名及大金额列保持在视口内；正值/零值及负结余保持当前语义；原排行点击行为正常。
- **实现证据**：`BillReportsScreen` 年账单摘要文案；`FinancialRankingRow` 的符号、`titleMedium` 字号与收支颜色参数；两个报告页面分别传入“+”/“−”和对应颜色。
- **验证证据**：BillReportsScreenTest、SalaryScreensTest 报告金额/颜色用例；API26全量173项通过。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：不适用：未延期。

- **验收标准**：仪器测试覆盖图标与“其他”回退、收支颜色、可访问文本、40dp图标格、18dp左右边距、金额右边缘和点击编辑；窄宽和大字体下长金额限宽省略且不溢出视口。

### REQ-003 — 工资收入项连续明细

- **需求**：收入项明细移除月份分组和月现金/非现金小计，直接按日期倒序显示每笔工资记录；日期改为“6月25日”格式并保留现金性质、图标和金额。保留筛选、编辑、左滑删除、确认及返回链。
- **验收标准**：仪器测试覆盖跨月连续列表无月份标题/小计、日期格式、倒序、选中收入项过滤、编辑/删除刷新与返回行为。
- **实现证据**：`SalaryHome` 对 `summarySubtitle`（收入项详情）直接遍历所选年份过滤后的记录，按日期和更新时间倒序，不生成月份组；`SalaryEntryRow` 日期使用“M月d日”并保留现金性质、滑删、编辑。
- **验证证据**：SalaryScreensTest 覆盖跨月无月组、日期格式、筛选、编辑/删除刷新；API26全量173项通过，API34相关用例通过。
- **状态**：VERIFIED

## 决策

### DEC-001 — 页面样式一致性与明细列表结构

- **状态**：RESOLVED
- **确认路径**：用户确认四组八屏高保真稿，并补充工资明细取消月份分组、报告金额带正负符号。
- **决定**：复用现有主题和共用行/卡片；保留页面各自的切换栏；分类明细显示图标；工资收入项详情使用不分月的连续记录行。
- **原因**：实机对照发现相同功能页面的记录行和金额表达不一致。
- **取舍**：工资详情不再呈现月分组汇总；逐笔现金性质仍保留。
- **证据**：用户批准的高保真稿与明确补充要求。
