## 工作概述

工资总览从月/年/全部三态切换改为按年/全部浏览，设置页提供工资 Excel 导入导出和收入项管理。版本 0.5.1/code16 已完成本地构建及验证，GitHub 推送与 Release 发布进行中。

## 范围与验收

### REQ-001 — 工资按年/全部浏览与设置管理

- **需求**：工资页按年或跨年展示记录，年份默认为当年；工资维护入口集中放在设置。
- **验收标准**：年度范围为 1900 至当前年；全部模式覆盖跨年记录；统计和明细匹配选择范围；导出全部或指定年份；管理页往返不丢工资编辑草稿或导入状态；UI 与批准稿一致。
- **实现证据**：`SalaryScreens.kt` 年度/全部首页及管理路由；`SettingsScreen.kt` 工资管理区；`MainActivity.kt` 设置来源导航与 SAF 有效性处理；`SalaryScreensTest` 和 `UpdateSettingsScreenTest`。
- **验证证据**：`:app:testDebugUnitTest`、`:app:lintDebug`、API26/API34 各 134 项仪器测试均通过。`build-release-macos.sh` 核验正式 APK 包名 `app.caiji.android`、0.5.1/code16、minSdk26、targetSdk34、v2 签名、zipalign 与 SHA-256。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：不适用：未延期。

## 决策

### DEC-001 — 工资按年或全部记录浏览

- **状态**：RESOLVED
- **确认路径**：用户批准高保真设计和实施计划。
- **决定**：默认设备当前年；用户可选 1900 至当前年任一年，或跨年查看全部；全部模式顶部右侧显示“全部记录”。
- **原因**：移除月筛选和标题菜单，为逐笔收入明细增加展示空间。
- **取舍**：不提供月度工资筛选；按年与全部切换保留本次工资页面中选择的年份。
- **证据**：用户批准的工资页面高保真稿和本 Work Item 验收标准。
