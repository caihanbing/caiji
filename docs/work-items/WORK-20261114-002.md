## 工作概述

按批准的高保真稿，为账单与工资汇总金额增加隐私显示切换，并在设置中增加账单支出备注最低金额。最低门槛默认关闭，配置仅保存在本机。

## 范围与验收

### REQ-001 — 需求摘要

- **需求**：汇总进入时默认隐藏指定金额；设置阈值后，达到或超过阈值的新增和编辑支出必须填写备注。
- **验收标准**：账单结余/收入与工资纯收入/收入按千位及以上数字逐位显示 `*`，金额低于千元保持原值，重新进入与 Activity 重建后默认隐藏；支出阈值含两位小数和 0 元，收入不受影响；禁用时维持原行为。
- **实现证据**：`PeriodControls.kt`、`BillReportsScreen.kt`、`SalaryScreens.kt`、`PrivacyAmountFormat.kt` 实现卡片切换；`MainActivity.kt` 和 `SettingsScreen.kt` 保存本机设置；`EntryEditorScreen.kt`、`LedgerViewModel.kt`、`LedgerRepository.kt` 校验新增和编辑。

## 决策

### DEC-001 — 汇总金额隐藏规则

- **状态**：RESOLVED
- **确认路径**：用户确认设计稿及需求选项。
- **决定**：账单汇总仅隐藏结余和收入，工资汇总仅隐藏纯收入和收入；每位千位及以上数字替换为 `*`；每次进入和 Activity 重建均隐藏。
- **原因**：保护卡片中的指定金额，同时保留低位及其余摘要可读性。
- **取舍**：金额位数仍可由星号数量推知；表格和其他金额保持原样。
- **证据**：批准稿；`PrivacyAmountFormat.kt` 和 `PrivacySummaryCardTest.kt`。

### DEC-002 — 支出备注门槛存储和校验

- **状态**：RESOLVED
- **确认路径**：用户确认设置为本机偏好，不纳入账单备份。
- **决定**：阈值默认关闭，以整数分保存在 `ledger_preferences` SharedPreferences；新增和编辑支出统一校验，恢复备份不调用此校验。
- **原因**：保持账单 Room schema 和加密备份格式不变。
- **取舍**：换设备后需重新设置门槛。
- **证据**：`MainActivity.kt`、`LedgerRepository.kt`、`ExpenseNoteRequirement.kt`。

## 风险

### RSK-001 — 风险摘要

- **状态**：MITIGATED
- **确认路径**：API26/API34 仪器回归和 Repository 单测。
- **概率**：低
- **影响**：错误金额遮罩可能泄露摘要数字；错误阈值比较可能拒绝有效账单或漏掉必填备注。
- **缓解措施**：遮罩只作用于格式化展示，业务数据不变；金额解析、比较与 Repository 校验均使用整数分。
- **验证**：千元边界、超大金额、负结余、0 元、阈值边界、新增、编辑及收入豁免用例通过。
