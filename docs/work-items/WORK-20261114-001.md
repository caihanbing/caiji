## 工作概述

按用户实机检查发现，工资收入录入的字段选择入口和金额汇总顺序与记账页的操作层级不一致；用户另要求检查相似功能页面的控件样式。本轮高保真收入录入对照稿已明确获得用户确认。实施时需保留青竹主题、所有页面既有业务能力与管理页历史收入项语义。

## 范围与验收

### REQ-001 — 需求摘要

- **需求**：新增收入页增加同记账页一致的收入项管理入口；金额 dock 顺序和样式按批准稿排列；全面核对同类 UI 的一致性并修正确证的漂移。
- **验收标准**：入口样式与管理路由正确，返回保留草稿、现金性质和当前输入字段；摘要、金额、56dp 字段选择行、键盘顺序正确；不同主题及受支持窄窗口下无关键遮挡或不可达控件。
- **实现证据**：`SalaryScreens.kt` 通过 `SR.EDIT` 返回并提升活动金额字段状态；编辑页标题增加“管理收入项”；dock 顺序与字段行高度按稿调整。
- **验证证据**：API26/API34 各 197 项仪器测试、JVM 单测、Lint 和签名 Release 构建通过。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：不适用：未延期。
