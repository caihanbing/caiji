## 决策

### DEC-001 — 收入项编辑与 Excel 恢复规则

- **状态**：RESOLVED
- **确认路径**：用户批准的高保真稿及本轮关于编辑字段、图标范围和 Excel 冲突优先级的选择。
- **决定**：内置和自定义收入项均可改名/换图标，现金性质编辑时固定；工资页面全处复用同一图标。Excel 按稳定 ID 优先识别，本机已有目录优先；仅空白且预置目录未自定义的首次恢复从文件恢复预置名称和图标。
- **原因**：保存用户确认的收入项目录外观，同时避免意外改变历史工资现金分类。
- **取舍**：新版 Excel 附加可选目录元数据；旧版不能完整恢复新增图标和预置改名。
- **证据**：批准设计及 `docs/superpowers/specs/2026-11-06-salary-icons-and-ui-consistency-design.md`。

## 风险

### RSK-001 — 工资库迁移与收入项目录导入

- **状态**：MITIGATED
- **确认路径**：代码审查及 API26/API34 v1→v2 覆盖升级与回滚测试。
- **概率**：中
- **影响**：迁移或 Excel 恢复错误可令项目图标/名称丢失，或错误重分历史现金统计。
- **缓解措施**：显式 Room Migration；Cash / ID 不可变；目录恢复与工资导入在同一事务；旧格式读取保留；对全新和已有目录分开验证。
- **验证**：完整 schema 1 fixture 迁移测试在 API26/API34 验证所有预置项映射、全部目录属性及完整工资行保持；注入失败后确认 user_version、列和原工资目录回滚。另测预置名称交换/链式恢复和 Excel 稳定 ID 冲突处理。
