## 工作概述

修复财记 0.3.0 实机回归发现的水平手势无响应、分段标签迟滞、反馈图片预览失败和顶部栏样式不一致。采用用户批准的最新高保真稿；发布同签名 0.3.1 并验证现有用户数据保留。

## 范围与验收

### REQ-001 — 记账与账单横向切页

- **需求**：记账页从金额、分类及其他 Pager 内容区支持收支横滑；短表格可直接切月/年，长表格先滚动且边界的剩余位移交给 Pager。
- **验收标准**：触摸起点覆盖金额区、分类项、短账单行及长金额表格；双向页边界不循环；长按排序、纵向滚动、键盘和系统返回互不误触。
- **实现证据**：`EntryEditorScreen` 由两页 Pager 包含金额/分类内容；移除账单表格无条件消费剩余位移的 nested-scroll 回调。
- **验证证据**：API 34 测试覆盖金额起点、分类起点、短行直接切页、长表格滚动和边界接力。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：实机验证横滑手感。

### REQ-002 — 分段标签连续跟随

- **需求**：记账、分类管理、账单、报告排行标签随 Pager 拖动进度连续移动；业务状态在页面停稳后提交。
- **验收标准**：中段拖动、反向拖动及标签点按时高亮与 Pager 同步；报告查询只在最终停靠页触发，加载/失败不显示旧收支类型排行。
- **实现证据**：共用 `PagerSegmentedTabs` 使用 `currentPageOffsetFraction` 绘制指示器与插值文字色；现有 `settledPage` 副作用保留。
- **验证证据**：API34 可控时钟标签测试、四组 Pager 手势及旧类型报告隔离测试；全量 90 项通过。
- **状态**：VERIFIED

## 决策

### DEC-001 — UI 实现范围

- **状态**：RESOLVED
- **确认路径**：用户在本轮批准顶部栏与反馈截图区高保真稿。
- **决定**：仅统一稿中顶部栏结构并修复缩略图显示/横滚；不增加图片全屏查看。
- **原因**：按批准范围减少视觉漂移。
- **取舍**：反馈照片继续以单行缩略图呈现，通过横滑查看五张。
- **证据**：已批准稿 `exec-d34d738c-2948-4c2d-a658-778cffc924a1.png`。

### DEC-002 — 表格边界手势

- **状态**：RESOLVED
- **确认路径**：用户选择“先滚表格，到边界后剩余手势切页”。
- **决定**：保留 Compose 子横滚，并让未消费位移自然传给父 Pager；移除无条件消费位移的自定义 nested-scroll 回调。
- **原因**：短表格能切页，超宽表格仍能优先横滚。
- **取舍**：一次跨越边界的快速手势可能滚动表格后继续切页。
- **证据**：用户明确选择及 `shortBillRowPassesHorizontalSwipeToMonthYearPager`、`compactBillTableScrollsAsOneAndKeepsRowsClickable`。

### DEC-003 — 主题、标签和交互更新时点

- **状态**：RESOLVED
- **确认路径**：用户批准采用实时标签跟随，业务状态仍停稳后提交。
- **决定**：标签插值读取 Pager 当前位置；分类切换/报告查询仍以 `settledPage` 更新。
- **原因**：标签即时反馈同时避免滚动途中重复副作用。
- **取舍**：页面过半时标签已高亮目标页，报表数据在停靠后更新。
- **证据**：用户计划和 API34 中程触摸测试。

### DEC-004 — 0.3.0 覆盖升级基线

- **状态**：RESOLVED
- **确认路径**：正式构建清理输出目录时移除了本机版本化 0.3.0 APK；GitHub 没有相应 release asset。
- **决定**：从已推送的原始发布源码提交 `8d2f173` 重建同版本 code7/正式签名 APK作为覆盖升级基线。
- **原因**：验证实际 0.3.0 源码和正式证书对既有数据的兼容。
- **取舍**：该 APK 与原发布包的包名/版本/签名一致，但为从源码重建，字节哈希不是先前已删除的 APK 哈希。
- **证据**：重建基线 APK SHA-256 `589c382d91dac149e771811054ec3a92652f74f217c8ea955e5572a84b922997`，使用证书 SHA-256 `692d2387ba18f63ed43548d153af2a611384d8bffe1c603c3314df56ef006e1a`。

## Bug Fix 闭环

- **症状**：实机中记账/账单横滑无效，分类与报告标签切换迟缓，新增反馈的照片缩略图均不可用，三个功能页的标题栏样式不一致。
- **复现**：在 API34 UI 测试对金额显示、短月账单行、分类 Pager 中段和带暂存图片的反馈编辑页执行对应操作。
- **根因**：记账 Pager 仅包裹 210dp 分类网格；账单表格自定义 nested-scroll 将所有剩余横向位移消费；标签只在 `settledPage` 更新；暂存 ref 的 draftId 被重复拼接；标题栏由页面各自 Row 构造。
- **失败机制**：Pager 未收到触摸；同一页面的标签等待整页动画完成；缩略图读取的路径多一层 draftId；标题中心随两侧按钮宽度偏移。
- **修复**：扩大记账 Pager 内容区；移除表格无条件消费并用 Pager offset 绘制共用分段；验证并解析暂存引用一次；用共用居中顶部栏。
- **回归保护**：新增 `swipingFromAmountAreaSwitchesTypeAndKeepsAmountDraft`、`shortBillRowPassesHorizontalSwipeToMonthYearPager`、`compactBillTableScrollsAsOneAndKeepsRowsClickable`、`categoryTypeSelectionTracksSwipeBeforeThePageSettles`、`pendingScreenshotPreviewResolvesItsDraftPathOnce` 及顶部栏中心测试。
