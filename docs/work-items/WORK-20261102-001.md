## 工作概述

交付用户批准的高保真设计：设置页含本机问题反馈及五主题；记账分类长按拖动；四组支出/收入或月/年页面左右切换。反馈和截图独立于账本数据库及加密备份。

## 范围与验收

### REQ-001 — 本机问题反馈

- **需求**：设置增加问题反馈入口；问题包含必填标题、描述和最多 5 张选填截图，可查看、编辑、分享和确认删除。
- **验收标准**：问题和图片跨应用重启保留；截图导入到应用私有目录；编辑取消不覆盖原记录；删除问题清理关联文件；分享只向用户选择的系统接收应用提供本条文字及图片；账本恢复不修改反馈。
- **实现证据**：独立 `FeedbackDatabase`、`FeedbackRepository`、图片私有存储和受限 `FileProvider`；不改账本数据库 schema 或备份。
- **验证证据**：API34 反馈存储测试覆盖数据库重开、私有截图复制/清理、失效 URI；编辑必填字段仪器测试通过。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：实机验证系统图片选择和接收应用分享。

### REQ-002 — 五套外观主题

- **需求**：提供琥珀暖白、青竹、海盐蓝、雾紫、石墨深色五套主题，选择即应用并记住。
- **验收标准**：五套在全部页面、对话框、日期选择器和状态/导航栏使用对应颜色；默认保持琥珀暖白；重启后还原用户选择。
- **实现证据**：集中式主题色表与本机主题偏好；Material 色彩方案跟随当前主题。
- **验证证据**：主题色表单元测试验证 5 个不同主色；设置即时选主题与 Activity 重建恢复 SharedPreferences 仪器测试通过。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：实机检查深色文字和系统栏可读性。

### REQ-003 — 分类拖动及四组左右滑动

- **需求**：记账页长按拖动分类排序；记账、分类管理支出/收入，账单月/年，月/年报告支出/收入排行支持滑动切换。
- **验收标准**：拖动位置持久化并与分类管理同步；取消/保存失败恢复原顺序；点击现有分段项与滑动同步；拖动、表格横滚、垂直滚动、键盘和分类详情各自处理自己的手势；报告数据按最终停靠页更新。
- **实现证据**：Compose `HorizontalPager` 和分类网格长按拖动，沿用现有分类排序事务及报告请求门闩。
- **验证证据**：API34 仪器覆盖记账分类拖动写入目标顺序、记账草稿保持、分类/账单/报告四组横向切换；现有排序事务回滚与列表滚动测试通过。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：用户在实体设备核对手势边界。

## 决策

### DEC-001 — 反馈数据与备份范围

- **状态**：RESOLVED
- **确认路径**：用户选择“本机问题清单”、文字与截图及独立保存。
- **决定**：反馈和主题偏好保留在本机，不进入账本加密备份或账本恢复替换范围；分享只在用户明确点分享时发生。
- **原因**：账本恢复不应覆盖问题记录；反馈文本和截图属于用户明确选择分享的数据。
- **取舍**：卸载应用会移除反馈记录；账本备份不用于恢复反馈。
- **证据**：用户确认的设计选择及分离的 `FeedbackDatabase`。

### DEC-002 — 主题与滑动行为

- **状态**：RESOLVED
- **确认路径**：用户批准三张高保真稿和交互说明。
- **决定**：采用五套既定配色；点选立即应用；分类拖动改变共享排序；左右滑动停靠后再更新数据状态。
- **原因**：符合确认稿且避免切换动画中误保存分类/报表。
- **取舍**：报告排行切页后需读取对应类型报告。
- **证据**：本轮批准稿、对应 UI 与交互仪器测试。

## 风险

### RSK-001 — 截图数据安全和文件一致性

- **状态**：MITIGATED
- **确认路径**：仅复制用户选中的图片到私有目录；内容提供器使用窄路径映射和临时只读授权。
- **概率**：中。
- **影响**：失效 URI、写入失败或删除不同步可能造成丢图或残留文件。
- **缓解措施**：截图暂存、Room 事务提交、失败删除新文件，删除记录时清理其关联文件；分享前逐项验证文件存在。
- **验证**：`FeedbackRepositoryTest` 覆盖独立 DB 重开、截图私有复制/URI 可读、删除清理及失效 URI 回滚；反馈表单必填回归通过。

### RSK-002 — Pager、拖动和子滚动的手势冲突

- **状态**：MITIGATED
- **确认路径**：拖动期间禁用 Pager；Pager 使用停靠页更新值；表格横向子滚动优先于父 Pager。
- **概率**：中。
- **影响**：分类误切页、排序目标错误或报告显示错误收支。
- **缓解措施**：保留原点击切换；拖动取消/失败回滚；报告按停靠类型发起请求并丢弃旧请求。
- **验证**：79 项 API34 仪器、记账拖动和顺序持久化、四组 Pager 点击/手势同步，以及表格和垂直列表滚动测试。
