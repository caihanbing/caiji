## 决策

### DEC-001 — 已批准的收入项停用与迁移规则

- **状态**：RESOLVED
- **确认路径**：用户选择“仅限制手工新选”及“启停与顺序随 Excel 恢复”，并批准六屏稿。
- **决定**：停用只隐藏手工新增/改选项，历史记录和 Excel 导入可继续关联，导入不自动启用项目。V3 元数据携带启停与顺序；空白默认本机目录才恢复文件目录配置，已有本机项目设置优先，文件缺项按文件相对顺序追加。
- **原因**：保留历史工资引用，同时让 Excel 可作为收入项目录迁移载体。
- **取舍**：V2 旧文件继续导入，但没有启停和自定义顺序的恢复信息；新图标不保证被旧版白名单识别。
- **证据**：已批准实施计划及现有 V2 元数据实现。
