## 决策

### DEC-001 — 工资存储与账本隔离

- **状态**：RESOLVED
- **确认路径**：用户批准的实现计划。
- **决定**：工资独立保存在 Room 数据库；账本加密备份格式 2 保持不变。
- **原因**：减少既有账本数据库及备份格式的升级风险。
- **取舍**：工资需通过 XLSX 单独备份和迁移。
- **证据**：已批准的设计及 Room 和 Repository 测试。
