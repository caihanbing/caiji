## 工作概述

根据用户实机截图，将明细每日收入/支出摘要和月、年账单三项金额对齐到距屏幕右边 18dp 的内容边界。金额列等宽填满可用宽度，长表格继续整体横向滚动。按已确认的 UI 稿实施，不涉及数据格式变化。

## 范围与验收

### REQ-001 — 每日摘要右对齐

- **需求**：每日收入、支出汇总整组对齐至页面右侧 18dp 内容边界。
- **验收标准**：仅收入、仅支出及收入/支出同时存在时，显示文字的实际右缘均与边界重合；超长摘要仍可横向查看。
- **实现证据**：`app/src/main/java/app/caiji/android/ui/LedgerScreens.kt` 使用右侧对齐视口包裹横向摘要。
- **验证证据**：`LedgerScreensTest` 像素坐标断言覆盖单项和双项摘要；长金额滚动回归通过。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：用户实体设备布局回归。

### REQ-002 — 月/年结余对齐与列宽分配

- **需求**：收入、支出、结余列等宽并分配表格剩余宽度；结余实际文字右缘对齐至 18dp 内容边界。
- **验收标准**：表头和数据列位置一致；零值、负结余、实机样例金额以及 320dp/1.3 字体下均正确；超出屏宽时整表滚动，横滑至末端后右缘对齐。

## 决策

### DEC-001 — 对齐边界与窄屏行为

- **状态**：RESOLVED
- **确认路径**：用户批准 0.2.3 UI 稿。
- **决定**：每日摘要和表格结余共用距屏幕右边 18dp 的内容边界；三项金额等分期间列和内边距之外的可用空间；过宽表格继续整表横向滚动。
- **原因**：消除每日摘要左悬空及表格结余右侧空白，同时与账单金额边界一致。
- **取舍**：极长金额仍需横向滑动到表格末端。
- **证据**：用户确认的 UI 稿、实机截图和本 Work Item 回归测试。

## 风险

### RSK-001 — 不同屏宽与字体下的列几何

- **状态**：MITIGATED
- **确认路径**：像素级 Compose 仪器断言及 API34 设备回归。
- **概率**：中。
- **影响**：数字裁切或结余无法抵达右侧边界。
- **缓解措施**：依据视口宽度、期间列宽、内边距和金额最小宽度计算列宽；超出视口时保持同一横向滚动容器。
- **验证**：393dp AVD 样例、320dp/1.3 字体及超长金额场景测试。

## Bug Fix 闭环

- **症状**：用户截图显示每日摘要短内容停在栏左侧，月/年表格结余右侧留有明显空白。
- **复现**：用单笔收入/支出渲染每日摘要；用截图中的 ¥390,795.53 与 ¥391,323.53 渲染月/年表格。
- **根因**：每日摘要区域有宽度但行内容未右锚定；表格 numericWidth 未纳入且未分配期望边距剩余宽度。
- **失败机制**：行内内容按起始位置布局；表格内容总宽度小于滚动视口，未填满末列至目标边界。
- **修复**：右侧对齐容器包裹摘要；表格扣除期间列与内边距后均分三列，末列用右端盒定位文字。
- **回归保护**：API34 仪器测试用实际文本坐标与像素检测右边缘；覆盖单/双项、月/年、0/负值和超长金额。
