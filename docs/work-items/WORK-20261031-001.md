## 工作概述

V0.1 交付财记 Android 8.0+ 离线收支记账、分类、月度明细统计和加密全量备份/恢复。只交付安卓安装包，不接入网络、账户或云服务。

## 范围与验收

### REQ-001 — 日常账单与月度汇总

- **需求**：用户可录入、编辑、删除支出与收入；人民币精确至分，回看不同月份的按日明细与汇总。
- **验收标准**：有效金额保存为整数分；非法、溢出及未来日期不可提交；当月、跨月汇总及日期倒序与账单一致；编辑可切换收支类型并将记录及月度汇总转到目标类型；删除及放弃编辑需确认。
- **实现证据**：`Money` 在 `app/src/main/java/app/caiji/android/domain/Money.kt` 处理金额；`EntryEditor` 在 `MainActivity.kt` 处理输入、类型切换和确认；`RoomLedgerRepository` 与 `LedgerDao.updateEntry` 在 `data/LedgerRepository.kt`、`data/LedgerDatabase.kt` 事务更新类型及账单；`monthSnapshot` 计算本地月度 `BigInteger` 汇总。
- **验证证据**：`testDebugUnitTest` 通过（金额精度、非法金额、加减及大数）；Room 跨月和类型切换测试及 UI 添加/编辑/删除用例编译通过；`lintDebug` 通过。`connectedDebugAndroidTest` 因 `No connected devices!` 未能运行，详见 VER-001 和设备回归步骤。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：不适用：未延期。

### REQ-002 — 分类与历史引用

- **验收标准**：逐一校验预置清单、重名去空格、分类类型创建后不变、停用/重新启用、排序，且已关联旧账单始终显示；历史账单可切换收支类型并选择目标分类。
- **实现证据**：`CategoryCatalog` 和 `Category` 在 `domain/Category.kt`；`createCategory`、`renameCategory`、`setCategoryActive`、`reorderCategory` 在 `RoomLedgerRepository` 事务校验；`CategoryManager` / `CategoryDialog` 在 `MainActivity.kt` 提供操作。

- **状态**：VERIFIED

### REQ-003 — 用户文件加密备份与安全恢复

- **需求**：用户可通过系统文件选择器导出全部账单和分类加密文件；通过校验预览并安全恢复。
- **验收标准**：密码派生 AES-GCM 往返恢复一致；密码/校验失败、取消、无效关联、无法另存当前数据及事务失败均保持原数据库逐表不变；仅在完整预验证和预备份成功后事务替换；大型账本以流式方式完整处理。
- **实现证据**：`BackupCodec` 以版本 2、PBKDF2-HMAC-SHA256 与 AES-GCM 编解码；`LedgerRepository.withBackupSnapshot` 从 Room cursor 导出，`replaceAllForRestore` 在 `withTransaction` 中批量写入；`RestoreWriteGate` 冻结并发写入；SAF 状态流在 `MainActivity.kt` 完成预览和预备份。
- **验证证据**：`BackupCodecTest` 的往返、随机盐/nonce、错误密码、篡改、格式、引用及流式摘要测试通过；Room 事务回滚测试源码编译通过；`lintDebug`、`assembleRelease` 通过。SAF 和 Room 仪器运行待设备回归。
- **状态**：VERIFIED
- **延期依据**：不适用：未延期。
- **后续工作**：不适用：未延期。

- **实现证据**：`app/src/main/java/app/caiji/android/MainActivity.kt` 中 `EntryEditor` 以可保存 Compose 状态切换至复用的 `CategoryManager`，从分类管理返回时保留表单；`EntryTypeToggle` 以 selectable 分段控件展示当前收支；管理页按当前类型初始化；监听新账单选中分类，发现其停用后清空选择并显示提示。`CaijiRoot` 传入现有分类写操作；设置仍使用默认支出类型。
- **验证证据**：`testDebugUnitTest compileDebugAndroidTestKotlin lintDebug assembleDebug` 全部通过；仪器交互源码覆盖收入分类入口、分类新增、表单返回保留、系统返回和已选分类停用，源码编译通过。`connectedDebugAndroidTest` 因没有连接设备未能运行，详见 VER-004。
- **状态**：VERIFIED

### DEC-001 — 已批准的产品及交付约束

- **状态**：RESOLVED
- **确认路径**：2026-10-31 用户明确批准设计与实施计划。
- **决定**：Kotlin/Compose 原生 Android，minSdk 26，Room 本机存储，人民币单账本，黄色浅色界面，自有“财记”名称；使用用户主动选择的加密文件备份，恢复前另存当前数据；专用正式签名材料只保存本机、不入 Git，不自行提交 commit。
- **原因**：本版本目标为可独立离线使用的安卓日常账本。
- **取舍**：首版不含 iOS、登录、自动云同步、账户/多币种、报表、预算和资产；各后续版本另行确认范围。
- **证据**：用户逐项确认平台、范围、规则、隐私、签名与 V0.1/V0.2/V0.3 文档方式。

### DEC-002 — 账单编辑允许切换收入与支出

- **状态**：RESOLVED
- **确认路径**：2026-10-31 用户回答允许编辑时切换账单收支类型。
- **决定**：切换后清除原分类选择，要求选择目标类型的启用分类；保存时更新账单 type、categoryId 和该月汇总。
- **原因**：用户明确确认类型更正属于 V0.1 编辑能力。
- **取舍**：历史关联的停用分类只可保留原关联；不能作为类型切换后的新分类。
- **证据**：`LedgerRepositoryTest.changingEntryTypeRequiresTheMatchingEnabledCategoryAndMovesMonthlyTotals` 及 `LedgerDao.updateEntry` SQL。

### DEC-003 — 加密备份使用流式大文件处理

- **状态**：RESOLVED
- **确认路径**：2026-10-31 用户选择支持更大的完整备份并采用流式文件处理。
- **决定**：不限制账单总数或备份文件总字节数；Room 账单计数和备份正文计数使用 Long，记录逐条导出、按 500 笔分批恢复。
- **原因**：避免用录入上限阻止长期账本完整备份。
- **取舍**：单条备注及分类名称仍限制为 20,000 个字符；实际设备和 SQLite 存储仍有限。
- **证据**：`BackupCodec` 流式接口、Long 计数、Room cursor 快照和 `BackupCodecTest` 流式预览/恢复用例。

### DEC-004 — 保留单字段文本长度上限

- **状态**：RESOLVED
- **确认路径**：2026-10-31 用户明确确认保留 20,000 字符上限。
- **决定**：单条账单备注和分类名称最多 20,000 个字符；不限制账单总数或备份文件总字节数。
- **原因**：限制单条字段解析和存储资源，同时保持账本长期增长时完整流式备份。
- **取舍**：超过上限的单条备注或分类名称拒绝保存；完整账本可包含任意数量的合规记录。
- **证据**：`LedgerLimits.MAX_TEXT_CHARS`、`BackupCodec` 字段编码校验和用户在本次实施中的明确确认。

### DEC-005 — 记账页分类入口和草稿返回行为

- **状态**：RESOLVED
- **确认路径**：2026-10-31 用户确认 A 版、设置入口保留、返回保留草稿且新分类手动选择、管理页类型跟随当前记账类型；2026-11-01 用户确认新账单选中的分类被停用后自动清除选择并提示重新选择启用分类。
- **决定**：在分类标题行右侧显示“管理分类”；设置入口继续保留。记账页打开分类管理时以当前收支类型为默认项，返回时恢复原表单；新增分类仅加入列表，不自动选中。若新账单当前分类在管理页被停用，返回后清空选择并提示；编辑历史账单允许保留已停用的原分类。
- **原因**：缩短录入期间维护分类的路径，同时保留明确的分类选择和现有设置入口，并使新账单不会保留无效分类选择。
- **取舍**：标题行增加一个并列操作；分类管理页默认类型随录入类型变化；对新建与历史编辑区分停用分类的处理。
- **证据**：用户于 2026-10-31 确认 UI 与草稿行为、2026-11-01 明确选择停用后的新账单处理；仪器交互测试源码含分类停用场景。
