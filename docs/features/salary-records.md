## 快速上下文

底部“工资”页面提供工资和福利收入的独立记录及统计；首页默认显示当年记录，可选其他年份，左上“汇总”页显示跨年年度表，点击年份进入该年报告及收入项排行，再点击收入项查看该年逐笔明细。首页选择的年份由主导航根状态保存，在账单、图表、设置间切换及 Activity 重建后保留；新会话默认当年。首页月分组右侧同时显示现金与非现金纯收入（两项为零时也保留），不提供逐笔现金筛选或收入明细总计。年度报告收入项排行金额与工资首页记录金额同为16sp半粗收入绿并带“+”；金额列最大140dp，长金额单行省略。收入项明细逐笔按日期倒序连续显示，不按月份分组，日期为“M月d日 · 现金/非现金”。收入项管理按现金和非现金分页；同一项目目录按稳定顺序保存，列表只呈现当前性质，停用项目仍保留历史工资记录。新增项目的现金性质取当前分页，编辑性质固定。工资保存在独立 caiji-salary.db 中，不计入账单或账单加密备份。设置页“工资”区域提供 Excel 导入、导出和收入项管理。导出支持全部或独立选择年份。

仅支持 .xlsx。SalaryXlsxCodec 使用样例格式模板生成和解析 Sheet1。导入先预览校验，确认后在单一 Room 事务内写入。XML 按 UTF-8/UTF-16 严格解码，采用 Android 可用的 namespace-aware DOM，不设置 Xerces 专有 feature；拒绝 DTD、实体声明和外部资源。导入错误区分文件级、应用级和单元格级，单元格错误显示 Sheet1 坐标、字段、当前值及修改建议。导出成功显示绿色成功状态；非现金合计公式逐列按“全部合计减现金合计”计算。

## 目标与边界

### 目标

- 单独记录工资、补贴、积分、卡券及退税收入。
- 按年及全部记录统计，并查看单笔工资。
- 通过样例版式工作簿导入和导出。

### 范围内

- 工资首页默认显示当前年，可在 1900 至当前年浏览；年份随账单、图表和设置之间的主导航以及 Activity 重建保留，新会话默认当前年。左上汇总进入跨年年度表，列表日期包含年份。
- 记录日期、收入项、毛收入、工会费、养老保险、医疗保险、失业保险、公积金、企业年金及税。
- 提供样例全部 17 种收入项；收入项可改名、换 100 个图标、启停和调整顺序；管理页按现金/非现金分页，顺序只在同性质项目间移动；新增现金性质由当前页确定且编辑中固定；名称全局唯一。
- 自动计算纯收入并按期间统计现金和非现金合计。
- 年度摘要以本年纯收入为主金额，下方显示本年收入和扣款；跨年摘要对应累计三项。摘要卡按完整期间计算。
- 年度明细按月份分组，跨年明细按年月分组；每组分别累计 `isCash` 与非现金记录的 `netIncomeFen`，以“现金 ¥… 非现金 ¥…”显示，零值保留。分组标题复用账单的日期/摘要布局，组内仅最后一笔后绘制通栏分隔线。
- 跨年汇总显示年份、毛收入、扣款和纯收入四列表格；从最早记录年连续列到当年，无记录年份金额为零，完全无记录时显示当年零值行。表格沿用账单的自适应列宽和同步横向滚动。
- 点击年度行打开该年报告卡和收入项纯收入排行。收入项按纯收入降序，收入金额相同时按目录顺序和名称排序；保留有历史记录的停用项，零纯收入记录也可出现在排行中。
- 点击收入项排行行进入该年该项目的明细，报告卡继续显示完整年度金额；编辑、左滑删除确认后刷新明细、排行、汇总表和首页金额。硬件/标题栏返回按明细、报告、汇总、首页逐层返回。
- 工资年度首页与账单主页使用相同的汇总入口位置、16dp 横向及 8dp 纵向顶栏间距；工资收入行、图标和左滑删除与账单保持一致，金额列最大宽度 140dp。
- 新增/编辑收入页的收入项选择区提供右侧管理入口；管理收入项按当前现金/非现金页打开，返回后保留草稿、现金性质及当前金额字段。新建默认现金且不预选项目，编辑恢复原项目和性质并默认展开金额键盘。切换性质保留日期、收入与扣款表达式、清空项目并收起键盘。
- 收入项网格沿用记账分类的四列紧凑图标样式。选中收入项后，底部录入区依次显示纯收入/扣款合计摘要、当前字段大号金额、可横滑八字段选择栏和应用内键盘；字段选择行高度 56dp，与记账备注字段对齐。未选有效收入项时隐藏整个底部录入区。字段顺序为收入、工会费、养老保险、医疗保险、失业保险、公积金、企业年金、税；键盘支持数字、小数、单次加减、退格、日期与保存，税字段提供正负切换。金额留空按零，不能把未完成或无效表达式静默转换为零。
- 工资列表支持左滑删除并确认；编辑页删除按钮位于顶栏右侧。
- 设置页工资区顺序为收入项管理、Excel 导入、Excel 导出；导入预览保留文件/应用/单元格错误、重复记录及整批确认语义；导出全部或指定年份，不依赖工资页当前浏览期间。

### 范围外

- .xls、云同步、多币种及服务器接口。
- 图表分析；当前底部图表入口只显示占位页面。
- 将工资记录纳入账本加密备份。

### 不变量

- 金额以整数分保存，汇总使用 BigInteger。
- 毛收入和税以外扣款非负；税允许负数；空值按零处理；纯收入不得为负。
- 工资日期不能晚于当前日期。
- 导入存在任何错误行时整批禁止写入。

## 业务行为

- 首页默认显示当前年，可在 1900 至当前年选择年份；左上“汇总”入口打开累计统计和年度表。
- 首页年份在底部页面间导航和 Activity 重建后保留；年度报告筛选年独立于首页所选年，返回首页时继续使用先前年份。
- 首页记录日期显示月/日，收入项明细显示完整年月日；首页按月分组并呈现现金/非现金纯收入摘要，点击工资记录可编辑。
- 年汇总表可以点击任意年份；报告按收入项稳定 ID 聚合，收入项明细只包含相应年及项目的记录。
- 录入及编辑支持七项扣款折叠和即时纯收入计算；新增八个金额表达式为空，空值按零参与校验；删除前确认。折叠状态提供准确方向的箭头和无障碍描述。
- 新建及编辑收入默认收起扣款，用户展开状态在页面重建时保留；切换收入项管理不再从表单进入。
- 收入项管理以现金/非现金分页显示项目；行含图标、名称、上移/下移箭头及启用开关，不显示现金性质文字。图标和名称都可点击编辑；停用项显示“已停用”。
- 停用项目保留历史和 Excel 导入引用，不出现在新建/改选清单中；全部停用时新草稿不预选项目且无法保存。
- 在收入项管理当前现金/非现金页创建时固定相应性质，默认图标为“其他”；编辑仅修改名称和图标，不改变现金性质、稳定 ID、顺序或工资记录。
- Repository 以 Room 事务启停收入项并单步调整同现金性质顺序；持久化全目录序号时只交换同性质相邻项目所在位置并压紧序号，另一性质顺序不变，停用项目也参与排序；名称唯一性仍覆盖全部项目。
- 设置中的导入复用样例 11 列结构及原校验、重复匹配和原子写入逻辑；取消文件选择停留在导入页；离页和重选时使旧请求失效。
- 导入旧格式通过原预置名称映射稳定 ID；新版 XLSX 同时写 V2 和可选 V3 目录元数据。V3 保存启停和顺序，本机已有项目配置优先，文件缺项按文件顺序追加；仅空库默认目录恢复文件预置项设置。未知图标回退“其他”。确认时目录恢复与工资写入同一事务提交。
- 设置中的导出默认全部记录，可选指定年份；成功后返回设置，取消保留所选范围供重试。
- 首页及累计摘要复用账单报告卡样式，以纯收入为主金额，下方展示收入和扣款；年度页期间控制与账单首页入口对齐。
- 分组标题复用账单的 `FinancialGroupHeader`，以 `BigInteger` 分别累计现金与非现金纯收入，固定显示两项及零值。每组最后一笔收入后显示 1dp 通栏分隔线，组内收入行之间无横线。
- 列表按年月分组，标题与条目日期统一账单字号和间距；左滑删除采用账单相同动作宽度与二次确认。工资金额列最大宽度为 140dp。
- 录入页仅在收入项可编辑时显示底部字段栏、当前金额、扣款和纯收入摘要及键盘；编辑初入展开，新增选择收入项后展开；现金性质切换时收起并保留全部八项金额与日期。系统返回与标题返回统一：新建八项金额全空直接返回，任一字段非空弹放弃确认；编辑按八项金额相对初始值是否变化确认，取消后保留草稿。
- 导入按日期、项目与全部金额构成的多重集匹配重复笔数；错误、取消及事务失败均不留下部分导入。
- 导出使用 SAF，包含全部收入、现金收入、非现金收入的明细公式、合计和下拉项目；非现金合计 C:K 每列由同列全部合计减现金合计得出，缓存值同步使用整数分汇总。

## API、事件与任务

### RoomSalaryRepository.save

- 校验日期、金额、扣款和收入类型后新增或更新一笔记录；失败由调用页面展示，不覆盖数据库内容。

### RoomSalaryRepository.createIncomeType / updateIncomeType

- 创建接收名称、现金性质和分类目录图标；更新通过稳定 ID 只修改名称和图标，在事务内重检唯一名称，不提供修改现金性质的参数。

### RoomSalaryRepository.setIncomeTypeActive / moveIncomeType

- 启停与按同现金性质单步调整顺序在 Room 事务内执行，并保持另一性质的相对次序。停用不删除项目或历史关联；重新启用依然校验全目录名称唯一。排序同时覆盖停用项，移位后全目录顺序压紧编号。

### RoomSalaryRepository.incomeTypeImportCatalog / importNew

- `incomeTypeImportCatalog` 一致读取目录并确认是否为空白默认目录；`importNew` 在一个事务内重验预置目录恢复条件、现金性质、多重集重复及收入项约束，再原子更新允许恢复的预置项（含启停与顺序）、插入缺失自定义项和工资。导入允许工资关联停用项目；本机已有项目优先，缺失项按文件次序追加。失败整笔回滚。

### SalaryXlsxCodec.importPreview

- 输入 XLSX、当前收入项目录、日期和首次恢复标志，返回有效工资行、分级错误、新建自定义项及可恢复的预置目录状态。不改数据库。`CaijiSalaryIncomeDirectoryV3` 保存启停/顺序；继续读取 V2 和 `CaijiSalaryIncomeTypes` 旧元数据；样例表可见 11 列不变。

### SalaryXlsxCodec.export

- 按样例格式把工资行、现金性质及新旧收入项目录元数据写入 XLSX 输出流；模板、可见列和合计公式不依赖网络。

## 数据模型与迁移

独立工资数据库 `caiji-salary.db` 当前为 Room schema 3。`salary_income_types` 以名称建唯一索引，并存储稳定 ID、现金性质、预置标记、顺序、`iconKey` 与 `active`；`salary_entries` 以收入项 ID 外键关联，保存本地日期、八项金额及创建/更新时间。`MIGRATION_1_2` 映射原图标，`MIGRATION_2_3` 为所有旧收入项补 `active=1`；工资记录及原排序不变。账本 schema 1 和账单备份格式 2 未更改。

## 核心流程

1. 首次读取时事务性插入 17 种固定样例收入项。
2. 总览加载工资及项目，由 SalaryReports 按期间聚合。
3. 表单以现金/非现金选择对应启用收入项；标题行的管理入口打开当前性质项目管理，返回保留表单草稿、性质及当前金额字段。
4. 输入 dock 按纯收入和扣款合计、金额、八字段选择和键盘排列；金额转换为整数分，验证后通过 Repository 保存。
5. XLSX 先完整解析成预览；用户确认后在 Room 事务中重新匹配重复并插入。
6. 导出时从本机读取项目和工资，按日期升序构建工作簿并写入用户选择的 SAF URI。

## 异常与边界条件

- 日期、金额格式、精度、收入项或纯收入不一致 — 显示具体 Sheet1 单元格、字段、当前值、原因和修改建议，阻止整批导入；输入金额无效时不生成依赖金额的净收入差额错误。
- 文件结构、XML 编码或内容损坏 — 显示文件级错误及 Excel/WPS 修复或另存建议，不出现“第 0 行”或零值统计。
- 未知项目、现金属性不匹配或净收入缓存不一致 — 显示错误，不写数据。
- 缓存中只有 K 列公式值的样例空行 — 忽略。
- 无效 URI、压缩包过大、部件数量超限、宏、外链、嵌入文件或 XML 外部实体 — 拒绝解析或写出并在界面反馈。
- 用户取消文件选择 — 数据库保持不变。

## 并发与幂等

导入确认时在事务内重读工资并按 SalaryDuplicateKey 多重集重新计数，处理并发确认不会重复累计。项目名称由数据库唯一索引约束。每条保存记录使用新 UUID。

## 安全与权限

工资保存在应用私有数据库；不通过网络传输工资数据，也不申请广泛存储权限。联网权限只用于 Gitee 优先、失败后回退 GitHub 的更新检查，不传输工资内容。Excel 经 SAF 授权流访问。ZIP 展开总量限制为 16 MiB、部件限制 40 个；严格解码 UTF-8/UTF-16 并在解析前拒绝 DTD/实体声明，通过拒绝外部资源的 EntityResolver 防止外部读取；拒绝宏、外部链接和嵌入内容。XLSX 是明文文件，由用户选择位置及保管。系统自动备份不包含工资数据库。
