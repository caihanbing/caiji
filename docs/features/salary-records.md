## 快速上下文

底部“工资”页面提供工资和福利收入的独立记录及统计；首页默认显示当年记录，可选其他年份，左上“汇总”页浏览全部跨年明细及累计统计。两页摘要均展示毛收入、纯收入和扣款；收入明细金额统计跟随现金筛选，列表按月或年月分组并显示组内笔数与纯收入。工资保存在独立 caiji-salary.db 中，不计入账单或账单加密备份。设置页“工资”区域提供 Excel 导入、导出和收入项管理。导出支持全部或独立选择年份。

仅支持 .xlsx。SalaryXlsxCodec 使用样例格式模板生成和解析 Sheet1。导入先预览校验，确认后在单一 Room 事务内写入。XML 按 UTF-8/UTF-16 严格解码，采用 Android 可用的 namespace-aware DOM，不设置 Xerces 专有 feature；拒绝 DTD、实体声明和外部资源。导入错误区分文件级、应用级和单元格级，单元格错误显示 Sheet1 坐标、字段、当前值及修改建议。导出成功显示绿色成功状态；非现金合计公式逐列按“全部合计减现金合计”计算。

## 目标与边界

### 目标

- 单独记录工资、补贴、积分、卡券及退税收入。
- 按年及全部记录统计，并查看单笔工资。
- 通过样例版式工作簿导入和导出。

### 范围内

- 总览默认当前年，可在 1900 至当前年选择年份或切换跨年全部；全部列表日期包含年份。
- 记录日期、收入项、毛收入、工会费、养老保险、医疗保险、失业保险、公积金、企业年金及税。
- 提供样例全部 17 种收入项；收入项可改名和换 48 个分类目录图标，现金性质在创建时确定且编辑中固定；名称全局唯一。
- 自动计算纯收入并按期间统计现金和非现金合计。
- 年度摘要显示本年毛收入、本年纯收入及本年扣款；跨年摘要显示累计三项。明细笔数与纯收入按当前现金筛选计算，摘要卡仍按完整期间计算。
- 年度明细按月份分组，跨年明细按年月分组；每组统计筛选后笔数及纯收入。列表字体、金额样式、40dp 图标及分隔线对齐账单明细。
- 新增/编辑收入表单不展示收入性质和收入项管理入口；项目管理仅从设置进入。新增金额字段保持空值并显示 `0.00` 占位符，编辑保留原金额；扣款收起箭头朝上、展开朝下并提供状态描述。
- 设置页独立提供收入项管理与 Excel 导入/导出；导入预览保留文件/应用/单元格错误、重复记录及整批确认语义；导出全部或指定年份，不依赖工资页当前浏览期间。

### 范围外

- .xls、云同步、多币种及服务器接口。
- 图表分析；当前底部图表入口只显示占位页面。
- 将工资记录纳入账本加密备份。

### 不变量

- 金额以整数分保存，汇总使用 BigInteger。
- 毛收入和税以外扣款非负；税允许负数；空值按零处理；纯收入不得为负。
- 工资日期不能晚于当前日期。
- 导入存在任何错误行时整批禁止写入。

## 业务行为

- 首页默认显示当前年，可在 1900 至当前年选择年份；左上“汇总”入口打开全量累计统计与跨年逐笔记录页。首页与账单汇总期间控件采用一致的 14sp 半粗年份文字。每个页面独立保存现金类别筛选和列表滚动位置。
- 首页记录日期显示月/日，累计汇总页显示完整年月日；工资汇总不提供添加按钮，点击记录可编辑，保存/删除后返回汇总并更新数据。
- 录入及编辑支持七项扣款折叠和即时纯收入计算；新增八个金额值为空，空值按零参与校验；删除前确认。折叠状态提供准确方向的箭头和无障碍描述。
- 新增工资记录时扣款明细默认收起，展开后可逐项录入；编辑已有记录保持展开；收入项管理返回时保留草稿及扣款展开状态。
- 收入项管理页右上添加新项，列表显示图标与现金性质并可点击编辑；收入编辑器项目选择列表、工资首页和汇总记录均按稳定收入项 ID 显示相同图标。
- 创建收入项指定现金性质和图标（默认现金/“其他”图标）；编辑仅修改名称和图标，不改变现金性质、稳定 ID、顺序或工资记录。
- 设置中的导入复用样例 11 列结构及原校验、重复匹配和原子写入逻辑；取消文件选择停留在导入页；离页和重选时使旧请求失效。
- 导入旧格式通过原预置名称映射稳定 ID；新版 XLSX 携带可选版本化的收入项 ID、名称、现金和图标元数据，本机同 ID/名称项目优先。仅工资记录为空且预置目录未自定义时恢复文件中的预置名称和图标；未知图标回退“其他”。确认时目录恢复与工资写入同一事务提交。
- 设置中的导出默认全部记录，可选指定年份；成功后返回设置，取消保留所选范围供重试。
- 首页摘要采用“本年毛收入”第一行及“本年纯收入、本年扣款”第二行；跨年汇总对应使用“累计”标签。现金/非现金金额不再出现在摘要卡中。
- 收入明细标题和年月分组显示当前筛选后的记录数及纯收入小计；条目与账单列表共用相同字号层级和间距。
- 新增与编辑表单去掉收入性质和收入项管理行；管理仍可从设置打开。仅新增草稿初始化为空金额，编辑草稿从现有工资行载入金额。
- 导入按日期、项目与全部金额构成的多重集匹配重复笔数；错误、取消及事务失败均不留下部分导入。
- 导出使用 SAF，包含全部收入、现金收入、非现金收入的明细公式、合计和下拉项目；非现金合计 C:K 每列由同列全部合计减现金合计得出，缓存值同步使用整数分汇总。

## API、事件与任务

### RoomSalaryRepository.save

- 校验日期、金额、扣款和收入类型后新增或更新一笔记录；失败由调用页面展示，不覆盖数据库内容。

### RoomSalaryRepository.createIncomeType / updateIncomeType

- 创建接收名称、现金性质和分类目录图标；更新通过稳定 ID 只修改名称和图标，在事务内重检唯一名称，不提供修改现金性质的参数。

### RoomSalaryRepository.incomeTypeImportCatalog / importNew

- `incomeTypeImportCatalog` 一致读取目录并确认是否为空白默认目录；`importNew` 在一个事务内重验预置目录恢复条件、现金性质、多重集重复及收入项约束，再原子更新允许恢复的预置项、插入缺失自定义项和工资。失败整笔回滚。

### SalaryXlsxCodec.importPreview

- 输入 XLSX、当前收入项目录、日期和首次恢复标志，返回有效工资行、分级错误、新建自定义项及可恢复的预置改名/图标。不改数据库。新目录元数据 `CaijiSalaryIncomeDirectoryV2` 可选，旧 `CaijiSalaryIncomeTypes` 三字段格式仍可读取；样例表可见 11 列不变。

### SalaryXlsxCodec.export

- 按样例格式把工资行、现金性质及新旧收入项目录元数据写入 XLSX 输出流；模板、可见列和合计公式不依赖网络。

## 数据模型与迁移

独立工资数据库 `caiji-salary.db` 当前为 Room schema 2。`salary_income_types` 以名称建唯一索引，并存储稳定 ID、现金性质、预置标记、顺序及 `iconKey`；`salary_entries` 以收入项 ID 外键关联，保存本地日期、八项金额及创建/更新时间。显式 `MIGRATION_1_2` 为旧自定义项填默认图标，为 17 个预置项按用途映射图标，不更新工资行、现金性质或顺序。账本 schema 1 和账单备份格式 2 未更改。

## 核心流程

1. 首次读取时事务性插入 17 种固定样例收入项。
2. 总览加载工资及项目，由 SalaryReports 按期间聚合。
3. 表单将人民币转换为整数分，验证后通过 Repository 保存。
4. XLSX 先完整解析成预览；用户确认后在 Room 事务中重新匹配重复并插入。
5. 导出时从本机读取项目和工资，按日期升序构建工作簿并写入用户选择的 SAF URI。

## 异常与边界条件

- 日期、金额格式、精度、收入项或纯收入不一致 — 显示具体 Sheet1 单元格、字段、当前值、原因和修改建议，阻止整批导入；输入金额无效时不生成依赖金额的净收入差额错误。
- 文件结构、XML 编码或内容损坏 — 显示文件级错误及 Excel/WPS 修复或另存建议，不出现“第 0 行”或零值统计。
- 未知项目、现金属性不匹配或净收入缓存不一致 — 显示错误，不写数据。
- 缓存中只有 K 列公式值的样例空行 — 忽略。
- 无效 URI、压缩包过大、部件数量超限、宏、外链、嵌入文件或 XML 外部实体 — 拒绝解析或写出并在界面反馈。
- 用户取消文件选择 — 数据库保持不变。

## 并发与幂等

导入确认时在事务内重读工资并按 SalaryDuplicateKey 多重集重新计数，处理并发确认不会重复累计。项目名称由数据库唯一索引约束。每条保存记录使用新 UUID。

## 安全与权限

工资保存在应用私有数据库；不通过网络传输工资数据，也不申请广泛存储权限。联网权限仅用于 GitHub 更新检查。Excel 经 SAF 授权流访问。ZIP 展开总量限制为 16 MiB、部件限制 40 个；严格解码 UTF-8/UTF-16 并在解析前拒绝 DTD/实体声明，通过拒绝外部资源的 EntityResolver 防止外部读取；拒绝宏、外部链接和嵌入内容。XLSX 是明文文件，由用户选择位置及保管。系统自动备份不包含工资数据库。

## 关键决策

### 工资数据与账本隔离

- **决定**：使用单独工资数据库及 XLSX 备份。
- **原因**：维持账本 Room schema 1 和加密备份格式 2 兼容。
- **取舍**：工资需单独导出。
- **证据**：CaijiApplication、SalaryDatabase 及 Repository 测试。

### 重复工作簿行按多重集处理

- **决定**：使用日期、项目及所有金额字段组成重复键，按重复数量抵消。
- **原因**：允许合法的同日、同项目、同金额多笔收入。
- **取舍**：任一金额字段不同即为不同记录。
- **证据**：SalaryRepositoryTest.multisetImportSkipsExistingCopiesAndKeepsTheRemainingMultiplicity。
