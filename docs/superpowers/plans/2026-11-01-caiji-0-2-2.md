# 财记 0.2.2 实机反馈与剪贴板记账实施计划

> **For agentic workers:** 按下列任务顺序逐项验证，遵守 `$manage-feature-docs` 澄清门槛和项目 UI 设计确认要求。

**目标：** 交付经确认的八项 UI 优化和两种银行通知剪贴板预填功能。

**架构：** Compose 保持现有页面结构，纯 Kotlin 解析器产出类型、整数分金额和日期；Activity 在回到前台且取得焦点时读取一次剪贴板，Compose 协调去重、草稿保护与新建表单预填。

**技术栈：** Kotlin、Jetpack Compose Material 3、Android ClipboardManager、Room（现有 schema 1）。

**Spec：** `docs/superpowers/specs/2026-11-01-caiji-0-2-2-design.md`

## 全局约束

- Android `minSdk=26`、`targetSdk=34`；版本 `0.2.2`、`versionCode=5`。
- 主题沿用当前暖白与琥珀色；超出已批准 UI 稿的变更须重新确认。
- Room schema 1、加密备份格式 2 不变；签名密钥和密码不提交。
- 在当前 `main` 工作区完成并推送 GitHub `main`，不创建分支或 force push。

## 重点回归条件

- 摘要金额超过屏宽时能横向查看收入和支出；验证 320dp 与 1.3 字体。
- 空年份、1900 与当年边界都正确，年/月列表与报告同步。
- 同时收到通知与编辑草稿时不覆盖；备份流程完成后再显示待处理通知。
- 跨年日期向最近的非未来有效年份归属；闰日向前找到最近有效年份。
- 通知中的账号和余额不能被误当交易金额；重复通知在取消后仍不重开。
