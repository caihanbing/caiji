# 财记 0.2.0 实机反馈优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 根据用户已批准的 UI 设计发布财记 0.2.0，增加期间账单报告，简化记账和分类操作。

**Architecture:** Room 持续保存账单和分类；新增 Repository 汇总查询与 ViewModel 报告状态，Compose 负责报告导航和交互手势。数据库 schema 与备份格式不变；使用现有正式签名构建带版本号的 APK。

**Tech Stack:** Kotlin、Jetpack Compose Material 3、Room、JUnit、Android instrumentation、Gradle、Android SDK。

**Spec:** `docs/superpowers/specs/2026-11-01-caiji-0-2-0-design.md`

## Global Constraints

- 每项可见 UI 变化遵循项目 `AGENTS.md`：先有具体方案并取得明确确认；本方案已确认。
- Android minSdk 26，包名 `app.caiji.android`，Room schema 1，备份格式 2。
- 金额以正 Long 分值存储，汇总使用 `BigInteger`；保留当前账单规则和稳定分类键。
- Release 为 0.2.0/code 3，沿用本机 release 签名；私钥和密码不进入 Git。
- 任务完成后提交并推送当前分支，输出 `caiji-0.2.0-release.apk` 与 SHA-256。

## Review Focus

- 年月边界、闰日和累计值溢出由报告统计测试覆盖。
- 页面快速换期时的并发查询由 ViewModel 状态测试覆盖。
- 删除手势与纵向滚动竞争由 Compose 手势测试覆盖。
- 拖动分类失败/取消的一致性由 Repository 与 UI 测试覆盖。
- 新图标白名单与格式 2 恢复边界由 Catalog 和备份测试覆盖。
