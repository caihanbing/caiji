# 财记 0.2.1 实机反馈优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按用户确认稿完成明细、账单报告、记账输入和分类排序优化，交付 0.2.1 正式 APK 并快进推送 main。

**Architecture:** 继续在既有 Compose 页面和 Room Repository 内实现；提取共用期间箭头与汇总卡，复用排序事务，不改 schema 或备份接口。通过 Compose 仪器测试和版本化发布脚本验证最终行为。

**Tech Stack:** Kotlin、Jetpack Compose Material 3、Room、Gradle、Android API 34。

**Spec:** `docs/superpowers/specs/2026-11-01-caiji-0-2-1-design.md`

## Global Constraints

- UI 严格匹配 2026-11-01 用户批准稿；其他可见设计变化须另行确认。
- Room schema 1、备份格式 2、既有金额及草稿业务规则不变。
- 版本 `0.2.1`/code `4`，包名 `app.caiji.android`，minSdk `26`，沿用本地 release 签名。
- 在当前工作区工作，不创建新分支；验证通过后推送远端 `main`，禁止 force push。

## Review Focus

- 320dp/大字体/长金额下，日期仍在左，支出和收入两项摘要都完整可见；测试 `dailyDateAndTotalsRemainInSeparateHorizontalColumnsOnCompactScreens`、`compactDailySummaryKeepsBothLongIncomeAndExpenseValues`。
- 横向表头与数值列共享状态且项目行可点击；测试 `compactBillTableScrollsAsOneAndKeepsRowsClickable`。
- 日期选择取消和选日行为正确，今天/所选日期的辅助说明含完整年份；测试 `dateKeyOpensPickerAndOnlySelectionChangesDateLabel`。
- IME 完成恢复数字键盘后保存精确金额且只调用一次；测试 `keypadSaveIsTheOnlySaveActionAndImeDoneRestoresIt`。
- 分类排序失败或同帧快速重复点击不产生错误顺序/并发写；测试 `categoryArrowMoveLocksDuringSaveAndFailurePreservesOrder`。
