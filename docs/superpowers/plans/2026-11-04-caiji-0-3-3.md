# 财记 0.3.3 实机反馈修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复记账分类视窗截断和月年账单汇总切页闪动。

**Architecture:** 分类 LazyVerticalGrid 占用输入区上方的剩余约束；`BillReportsScreen` 按年份触发月、年列表统一加载，Pager 切换不触发查询。

**Tech Stack:** Kotlin、Jetpack Compose、Room、Gradle、Android API34 仪器测试。

**Spec:** `docs/superpowers/specs/2026-11-04-caiji-0-3-3-design.md`

## Global Constraints

- 版本 `0.3.3 / versionCode 10`，applicationId `app.caiji.android`，minSdk 26、targetSdk 34。
- Room schema 1、加密备份格式 2 不变；不得提交签名密钥或密码。
- 使用当前 `main` 工作区；推送 GitHub `main` 后创建 `v0.3.3` Release，并附 APK 和 SHA-256。
- 分类页只实现已批准的高保真稿。

## Review Focus

- 小屏或输入键盘展开时剩余高度很小：分类仍可纵向滚动、首末分类可达。
- Pager 从拖动取消或快速反向拖动：已加载汇总不消失，年份不变时不重新加载。
- 年份快速连续变化：旧年份查询仍受 ViewModel 请求序号保护，最终数据对应最后选择年份。
- 从报告编辑返回：账单页重新组合并加载最新值。
- 正式包签名、版本和升级兼容：与 0.3.2 正式签名一致且旧本地数据保留。
