# 财记 0.2.2 实机反馈与剪贴板记账设计

用户希望一次解决八项经实机验证的记账与账单交互问题，并在识别银行交易通知时快速进入待确认的记账表单。受众为财记 Android 用户。成功标准是窄屏能直接浏览每日收支和月度四列、记账表单紧凑且金额可点开、年份可在 1900 至当年之间浏览，并可安全识别两种指定通知而不重复覆盖草稿。

## 目标与边界

- 保持现有暖白与琥珀视觉主题、Room schema 1 和备份格式 2。
- 不自动保存剪贴板账单；用户仍需选分类和点击保存。
- 不申请网络或剪贴板后台监听权限；仅在应用取得窗口焦点后读取一次。
- 版本为 0.2.2/code 5，沿用原正式签名。

## 方案与取舍

- 使用单行每日摘要并允许摘要区域横向滑动，长金额仍可读。
- 月度表格缩窄期间列、三个金额列同宽；普通金额首屏可见，超长数值整体横滑。
- 记账备注和数字键盘固定为相邻底部输入区；上方分类区滚动。
- 将两类通知交给纯函数解析器；日期采用不晚于今天的最近有效年份。类型由已确认的交易类型推断，分类留空。
- 为保护草稿，活动编辑器或备份流程期间暂存最新通知；首次展示时记录 SHA-256 指纹，持久去重，不保留原文。
- 将浏览范围固定为 1900 年至当前年份；没有账单的年份照常显示零值。

## 验收

- 两个通知模板、字段分隔符、人民币金额、余额干扰、跨年、闰日、非法金额及溢出均被单测覆盖。
- UI 仪器测试覆盖每日收支同一行、年份上下界、账单四列布局、未选分类金额展开、备注键盘布局、剪贴板预填和重复读取。
- 全量 JVM、API 34 仪器测试、lint、正式签名 APK 元数据与 SHA-256 核验通过。
