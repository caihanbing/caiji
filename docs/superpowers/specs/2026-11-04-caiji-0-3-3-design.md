# 财记 0.3.3 实机反馈修复设计

## 意图

修复记账页分类区域在实机上被截断，以及月账单与年账单横滑停稳后汇总短暂闪动的问题。

## 目标与边界

- 记账页保持四列分类，在输入区收起时使用页面剩余空间；输入键盘显示时分类区收缩并可滚动。
- 月/年账单仅在进入页面、年份变化和用户重试时刷新，不因 Pager 页签切换清空或重读汇总。
- 不改变数据库、备份格式、分类次序、记账草稿规则及既有账单/报告交互。

## 方案

- 分类列表继续使用 Compose `LazyVerticalGrid`，去掉固定高度和外层纵向滚动，让分类网格填充金额/分类标题下方的约束空间。
- 账单页由 `BillReportsScreen` 按年份触发统一加载回调；Pager 页签变化只更新展示页，不触发加载。
- 按用户批准的实机截图改稿实现 UI：沿用原配色、图标、字体和四列网格，完整展示未选分类的列表。

## 验收

- API34 仪器测试确认收起状态网格大于原 210dp，可滚动并触达末项，展开输入后仍能访问分类。
- API34 仪器测试确认月/年双向横滑时汇总不归零或消失；切换年份加载一次，重试调用统一加载回调。
- JVM、全量 API34 仪器测试、Lint、正式签名 APK 检查通过。

## 约束

- 发布 `0.3.3 / versionCode 10`，Room schema 仍为 1，备份格式仍为 2。
- 同签名覆盖升级验证；源码及文档推送 `main`，创建带正式 APK 与 SHA-256 附件的 `v0.3.3` GitHub Release。
- 记账页布局以本设计及用户确认的效果图为准；其他视觉不变。
