# 财记 0.2.0 实机反馈优化设计

## 意图

依据用户完成实机验证后的八项反馈，延续已确认的“轻盈账本”视觉风格，完善启动图标、明细入口、账单分析、记账输入、分类维护和快速删除。用户是需要快速记账并查看本地历史账单的人。

## 目标与边界

- 明细页精简顶部信息，加入参考鲨鱼记账的月账单、年账单列表和期间报告。
- 记账页只保留一个保存入口；新增账单选分类后显示数字键盘，编辑可点击金额或分类显示键盘。
- 用长按拖动调整分类排序；将内置分类图标扩充为 48 个并按用途分组。
- 支持左滑打开单笔删除操作，始终二次确认。
- Room schema 保持 1；备份格式保持 2；金额分值与精确汇总规则不变；不增加服务端或外部 API。

## 已确认设计

1. **启动图标**：`#FFC847` 亮琥珀底、暖白圆角账本、深琥珀书脊和记账线，兼容圆形及圆角方形裁切。
2. **明细顶部**：删除“财记、本机账本、收支明细、按月查看”，顶部仅显示账单入口和月份切换；月份按钮为 48dp 触控区域内的细线圆角尖括号。
3. **月/年账单**：月账单按年份提供年度收支和各月表格；年账单显示历史总额和逐年表格。年月报告显示结余、收支、分类排行和对应明细，分类点击后过滤该期间账单。保持参考图“汇总行可钻取”的层级。
4. **保存与键盘**：固定保留底部“保存账单”；数字键盘的“完成”改为“收起”。新增进入时键盘隐藏，选分类后显示；类型切换时隐藏。编辑进入时隐藏，点击金额或分类展开。备注系统键盘显示时数字键盘隐藏。
5. **分类拖动**：去掉上下箭头。长按行抬起并振动，可在同类型（含停用分类）中拖动；靠边自动滚动；松手一次保存。取消或保存失败恢复原顺序。
6. **图标**：白名单图标键总数 48，旧键及默认分类 ID 均保持稳定；图标选择器按用途分组。Room 分类记录格式不变。
7. **滑动删除**：单条账单左滑展示红色“删除”按钮；点击后二次确认，取消不变，确认成功后同步刷新明细和汇总；同时至多展开一行。
8. **发布**：版本 `0.2.0`、`versionCode=3`，包名不变，沿用本机正式签名，正式 APK 名 `caiji-0.2.0-release.apk`，附 SHA-256。

## 兼容和回退

- 旧格式 2 备份可以由新版恢复。增加分类图标键后，旧版 0.1.1 无法恢复含未知键的新版备份；安装说明提醒用户回退前需评估备份版本。
- 新包使用当前本机签名，可以覆盖同签名旧包；发布前保存原账本加密备份。若安装或关键回归失败，可安装此前 APK 并恢复兼容的旧格式备份。
- 不修改 Room schema、默认分类 ID、账单业务规则或备份文件布局。
