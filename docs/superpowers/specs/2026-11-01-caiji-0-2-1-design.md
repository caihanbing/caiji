# 财记 0.2.1 实机反馈优化设计

## 意图

根据用户新一轮实机反馈，减少明细与账单页面的视觉噪音，让记账页在用户准备录入前保持精简，并把分类排序改成直接、可预测的点击操作。用户已批准轻盈账本方向和本稿的具体页面布局与交互。

## 范围与目标

1. 明细月份箭头去除底板及阴影，保留至少 48dp 透明点击范围；每日收支摘要置于日期右侧，小屏时仅摘要列内部换行。
2. 月账单年份切换放在顶部账单标题右侧，沿用明细月份箭头样式；年账单不显示年份控件。
3. 明细、月/年列表摘要和期间报告采用相同浅琥珀汇总卡：结余标题与金额在上方，收入、支出在下方并排。标题根据期间显示本月、所选年、全部账单或年月。
4. 月/年列表行保持“月份/年份、收入、支出、结余”四列，数值与表头逐列对齐且右对齐，行内不重复字段名。窄屏或大字体下表头和行作为同一横向滚动表。
5. 新增及编辑账单初始只显示顶部、类型、金额和分类。选择分类后显示日期/备注输入区和数字键盘。切换类型清除选择并折叠；编辑时保留既有账单内容，点金额或分类可展开。
6. 取消独立日期行；数字键盘“今天”打开日期选择器。今天显示“今天”，其他日期显示“M月d日”，内容描述包含年月日；取消不变更日期，禁止选择未来日期。
7. 数字键盘“收起”改为唯一“保存”入口，移除底部保存按钮。备注系统键盘与数字键盘互斥；IME 完成只结束备注输入并恢复数字键盘。保存使用原校验，禁用无效输入并防止并发点击。
8. 分类管理移除长按拖动及相关阴影/震动/边缘滚动，行内提供横排上/下箭头与启用开关。点击箭头移动一位，首尾按钮禁用；分类写入期间锁定可能冲突的排序与启停操作；失败保留原序并显示错误，成功顺序持久化。

## 非目标与约束

- 不改变金额计算规则、账单校验、草稿与放弃确认、分类 ID、分类停用语义、账单删除流程。
- 不增加外部 API，不改 Room schema 1、数据库结构、加密备份格式 2 或 48 个图标键。
- 沿用 Kotlin、Compose、Room、包名 `app.caiji.android`、release 签名和 minSdk 26。
- 发布版本为 0.2.1/versionCode 4；产物名 `caiji-0.2.1-release.apk`。

## 实施选择

- 提取可复用的期间切换箭头及汇总卡视觉，避免报告页与明细页继续分叉。
- 月/年表格使用共享横向滚动状态和确定列宽；点击期间行仍可进入报告。
- 使用记账页显式展开状态区分分类选择与金额/备注输入；日期继续使用 Android `DatePickerDialog`。
- 分类排序继续调用 Repository 既有事务 API；UI 通过目标索引及单次操作锁管理方向箭头。

## 验收

- Compose 测试覆盖明细日期摘要位置语义、报告卡/切换控件、窄屏表格滚动和点击、记账页初态/展开/日期/IME/唯一保存、分类箭头边界及失败回退。
- 执行 JVM 单测、Android 测试编译、lint、可用 API34 仪器测试及正式 APK 构建；在 320dp、大字体、长金额、长分类名和系统键盘下核对。
- 用同一 release 签名验证覆盖升级；验证 APK 包名、版本、minSdk、签名、zipalign 和 SHA-256。
- 本机及实机未运行的检查分别列明；不部署或重启后端服务。
