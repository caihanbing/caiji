# 财记界面统一与收入项编辑设计

## 意图

按已批准高保真稿统一导航、标题、期间箭头和工资收入项管理；收入项目录可改名换图标，并在工资相关界面同步展示。用户确认编辑不改现金性质，Excel 冲突时优先本机目录。

## 已批准界面与行为

- 底栏“记账”和账单空状态入口改为“记一笔”；编辑页标题保留“编辑账单”。收入项页名为“收入项管理”，工资编辑器入口和导入页分别称“收入项管理”“导入 Excel”。备份入口及弹窗称“加密备份”。修复 Excel 提示中的旧“工资 → 更多”路径。
- 使用共用 56dp 页面标题栏，使账单汇总、期间报告、分类明细及工资子页标题相对屏幕居中。账单月汇总年份控件放标题下一行右侧；年汇总不展示年份控件。工资年份箭头复用账单期间图标和点击区域。
- 收入项页右上角“＋ 添加”，删除底部新增按钮；列表点击可编辑，展示图标、名称和现金性质。编辑只允许改名与换图标，现金性质固定；新增允许选择现金性质，默认现金。收入项使用既有分类图标目录；工资选择、首页和汇总记录同步显示。

## 数据与兼容决策

- 工资 Room 从 schema 1 升到 2，收入项持久化 `iconKey` 并用显式迁移；旧自定义项默认图标“其他”，预置项按用途使用已有目录键。
- 稳定 ID、历史工资记录关联和现金性质不变。收入项名称去首尾空格，不能为空、最多 100 字符且全局唯一；图标键必须属于现有目录。
- XLSX 可见列和公式不变；额外存储版本化的收入项稳定 ID、名称、现金性质及图标元数据，兼容读取旧的 3 字段自定义项元数据。
- 导入按 ID 优先、名称其次；旧文件中的预置原名映射回原内置 ID。本机已存在的收入项名称和图标优先；只有工资记录为空、无自定义项且预置目录完全未自定义时，从文件恢复预置名称和图标。导入确认及目录恢复同一事务，预览和取消不写入，现金性质冲突仍拒绝整批写入。
- 只读旧 XLSX 可直接读取；不保证旧版应用识别新版收入项目录元数据。

## 兼容、测试和发布

不新增外部 API；账本数据库和账单加密备份格式不变。迁移需保留现有工资记录并测试失败回滚。使用 JVM、Lint、API26/API34 仪器测试和旧/新 XLSX 往返验证。版本发布为 0.5.3/code18，沿用既有正式签名；按项目交付要求更新功能档案、推送 `main` 并发布 APK 与 SHA-256 sidecar。用户实体设备结果未获得前保持待回归。
