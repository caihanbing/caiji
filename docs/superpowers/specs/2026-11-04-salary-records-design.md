# 工资记录与 Excel 导入导出设计

## 意图与边界

工资模块独立记录用户收到的工资、补贴、积分及卡券，不改变记账账单；底栏新增图表占位页及工资入口。本次不实现图表分析。

## 已批准界面

用户已批准本会话的工资功能高保真预览：总览按月/年/全部显示工资汇总及现金类型明细；新增/编辑表单输入日期、17 个内置收入项及金额，扣款可折叠，自动显示纯收入；管理收入项、Excel导入预览与导出，以及空状态。底栏顺序为明细、图表、记账、工资、设置，记账保持强调显示。

## 业务决策

- 独立 Room 数据库及 repository；工资不进入现有账本数据或加密备份。
- 货币按分保存；毛收入和除税额外的扣款为非负数，税额可为负数，空金额等于零，纯收入非负且为毛收入减扣款。
- 按样例汇总公式定义 17 个收入项的现金性质；自定义收入项名称唯一且显式指定性质。
- 仅处理 .xlsx。导入预览后追加；以日期、收入项和全部金额组成重复键，按重复笔数抵消；错误行阻止整批导入。
- 导出维持样例 Sheet1 的 11 列、列顺序和表格样式、冻结首行、收入项下拉及三类合计。使用公式重算纯收入与合计，并将非现金合计错误函数 MINUS 改为兼容表达式。
- 导出的隐藏列 M 提供包含内置及自定义收入项的命名范围下拉；OOXML 自定义属性携带收入项 ID 和性质。未知外部项需先在本机建立。
- ZIP 解压限制规模，拒绝不受支持的工作簿部件并使用安全 XML 解析；文件访问经 Storage Access Framework。

## 备选方案

采用总览和独立表单，保持手机端单笔录入与逐笔浏览清晰；相比在单屏横向滚动 Excel 网格，减少字段拥挤。采用独立数据库而非纳入账本加密备份，保持已有账本备份格式兼容，工资由 Excel 单独迁移。

## 验收

样例导入应识别 180 笔、17 种收入项，毛收入 1,038,302.00，纯收入 820,407.20，现金纯收入 756,580.20，非现金纯收入 63,827.00。导出后重导入零重复新增，并保留样例列、样式及金额精度；应用需通过 JVM、Lint、API34 仪器测试与版本化签名 APK 核验。
