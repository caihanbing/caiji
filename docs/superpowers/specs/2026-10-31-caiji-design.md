# 财记 V0.1 设计

财记是一款 Android 8.0+ 单用户离线记账应用，使用 Kotlin、Jetpack Compose 与 Room。本版本提供收支账单的增删改、分类维护、按日明细、月份切换、人民币月汇总，以及用户主动操作的密码加密全量备份和整库恢复。

记账默认支出和今天；分类必须主动选择。金额为正整数分，输入至多两位小数；支持加减计算、不可保存未来日期。账单按本地日期倒序显示。编辑时允许切换收入/支出，切换后须重新选择目标类型的启用分类；保存后同步更新类别关联和月度汇总。删除账单和放弃未保存的表单均需确认。

首次初始化通用收支分类。分类可新增、改名、选内置图标、排序、停用及重新启用；同类型启用分类去空格后不能重名，分类的收支类型不可改。停用分类继续保留历史关联，历史账单可保留原分类，新账单不可选用停用分类。

备份包含全部账单、分类、排序、启用状态及格式版本，以 AES-GCM 加密和每次随机盐、nonce、密码派生密钥保护。密码至少八个字符、导出需复核，应用不留密码。文件处理采用流式读写，不限制总备份字节数或账单总数；单条备注及分类名称最多 20,000 字符。恢复前先验证并显示数据摘要；现存数据库须先经系统文件选择器另存加密备份，再在确认后事务性替换。错误密码、损坏、不支持格式、取消或任意失败都保留原数据。应用不请求联网或广泛存储权限，禁用系统云备份中的账单数据，不集成广告或分析 SDK。

界面采用中文浅色黄色主题和自制图标，只暴露明细、记账、设置入口。版本范围：V0.1 为以上闭环；V0.2 报表与 V0.3 预算、资产仅作方向，在各自立项时另行确认。

已比较 Android Kotlin/Compose 与 Flutter，选 Compose 以匹配 Android 首发目标和现有 SDK。交付专用正式签名 APK，签名私密材料保留在本机、不入 Git；当前不发布应用商店、不创建 Git commit。V0.1 验收包括金额、日期、汇总、分类、持久化、加密备份错误路径、数据库迁移、签名覆盖升级和模拟器页面验证；最终还需用户完成真机回归。
